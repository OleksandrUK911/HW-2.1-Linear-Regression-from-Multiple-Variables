# 🚗 Прогнозування ціни автомобіля (Car Price Prediction)

Цей проект присвячений розробці моделі машинного навчання для прогнозування ринкової вартості автомобілів на основі їх технічних характеристик та історії володіння. Проект реалізовано мовою Python у середовищі Google Colab.

## 📂 Набір даних (Dataset)

Для навчання моделі використовувався датасет `cars.csv`, що містить інформацію про автомобілі та їх ціни (в індійських рупіях).

### Опис ознак (Features):
| Назва колонки | Опис |
|---|---|
| **Car_ID** | Унікальний ідентифікатор оголошення. |
| **Brand** | Марка автомобіля (наприклад, Toyota, Honda, Ford). |
| **Model** | Модель автомобіля (наприклад, Camry, Civic). |
| **Year** | Рік випуску. |
| **Kilometers_Driven** | Пробіг (км). |
| **Fuel_Type** | Тип палива (Petrol, Diesel та ін.). |
| **Transmission** | Тип трансмісії (Manual, Automatic). |
| **Owner_Type** | Кількість попередніх власників (First, Second, Third). |
| **Mileage** | Витрата палива (км/л). |
| **Engine** | Об'єм двигуна (CC). |
| **Power** | Потужність (bhp). |
| **Seats** | Кількість місць. |
| **Price** | **Цільова змінна**: Ціна автомобіля. |

---

## 🛠️ Етапи розробки

### 1. Завантаження та первинний аналіз
- Завантажено дані бібліотекою `pandas`.
- Проведено перевірку типів даних та наявність пропущених значень.
- Визначено типи ознак:
    - **Числові**: Year, Kilometers_Driven, Mileage, Engine, Power, Seats, Price.
    - **Категоріальні**: Brand, Model, Fuel_Type, Transmission, Owner_Type.

### 2. Попередній аналіз даних (EDA)
- Побудовано матрицю кореляції для числових ознак.
- Виявлено сильні кореляції цільової змінної `Price` з ознаками `Power`, `Engine` та іншими.

### 3. Підготовка даних (Data Preprocessing)
Дані було розділено на тренувальну (`X_train`) та тестову (`X_test`) вибірки у співвідношенні **80/20**.

#### Кодування категоріальних ознак:
- **Fuel_Type, Transmission**: Використано бінарне кодування (0/1).
- **Owner_Type**: Використано `OrdinalEncoder` зі встановленням порядку: `First < Second < Third`.
- **Brand**: Використано `OneHotEncoder` для створення бінарних колонок для кожного бренду.

#### Масштабування:
- Використано `StandardScaler` для стандартизації числових ознак (середнє = 0, дисперсія = 1).

### 4. Моделювання (Modeling)
Було побудовано лінійну регресійну модель за допомогою бібліотеки `statsmodels` (OLS - Ordinary Least Squares).

#### Процес відбору ознак:
1.  **Базова модель**: Побудована на всіх доступних ознаках.
2.  **Аналіз значущості**: Перевірено p-values для кожної ознаки.
3.  **Оптимізація**:
    - Виключено ознаки з p-value > 0.05 (статистично незначущі).
    - Побудовано нову модель тільки на значущих ознаках.
    - Проведено експеримент з м'якшим критерієм (p-value < 0.25).

---

## 📊 Результати

- **R-squared (R²)**: ~0.96 (Модель пояснює близько 96% варіації ціни).
- **Adj. R-squared**: ~0.95.

**Висновок**: Видалення статистично незначущих змінних не погіршило якість моделі, але зробило її простішою та більш інтерпретованою. Рекомендовано використовувати модель, побудовану на ознаках з p-value < 0.05.
